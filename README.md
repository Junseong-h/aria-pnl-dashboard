# 아리아 식음료 P&L 대시보드

GitHub Pages에 올릴 파일입니다.

## 업로드 방법

1. GitHub 저장소 `aria-pnl-dashboard`로 이동합니다.
2. 기존 `index.html` 파일을 엽니다.
3. `Edit this file` 또는 연필 아이콘을 누릅니다.
4. 이 폴더의 `index.html` 내용으로 전체 교체합니다.
5. `Commit changes`를 누릅니다.
6. GitHub Pages 주소를 새로고침합니다.

## 포함 내용

- 식음료 BEV P&L 대시보드
- 전년대비 음료, 와인, BEV 매출 비교
- PRO, Beer, KLQ, SDR 개별 매출 비교
- 월별, 분기별, 상반기/하반기, 연간 차트
- 모바일 대응 레이아웃

## 실행 방식

별도 서버나 데이터베이스가 필요 없습니다. `index.html` 하나로 실행됩니다.
